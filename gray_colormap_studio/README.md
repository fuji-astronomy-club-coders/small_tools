# Gray Colormap Studio

複数の画像を読み込み、Matplotlib ベースの表示操作・輝度範囲選択・等輝度線表示・一括保存を行う PyQt6 デスクトップアプリです。FITS の科学画像にも対応しています。

## 主な機能

- PNG / JPEG / TIFF / BMP / WebP / FITS の読み込み
- TIFF / FITS の画素値を元のデータ型・ビット深度のまま保持
- FITS は最初に画像データを持つ HDU を自動選択
- ヒストグラム（画素数を対数軸表示）とカーソル値・階級・画素数の表示
- ヒストグラムをドラッグして表示する輝度範囲（vmin / vmax）を選択
- ヒストグラムをクリックして指定輝度の等輝度線（contour）を画像上に描画し、ヒストグラムにも赤い破線と数値で表示
- Matplotlib の imshow オプションに対応したカラーマップ、補間、origin、aspect の変更
- 画像オペレーション欄の折りたたみ・展開
- プレビュー画像の拡大・縮小・全体表示（ボタンおよびマウスホイール）
- カラーバーの表示切り替え
- 選択画像または全画像の RGB PNG 一括保存

## セットアップ

Python 3.10 以上で、次を実行します。

```powershell
python -m pip install -r requirements.txt
python run.py
```

## 操作方法

1. 「画像を追加」で画像を読み込み、一覧から表示対象を選択します。
2. ヒストグラム上を左右にドラッグすると、その範囲を表示用の vmin / vmax に設定します。範囲外の画素は表示上クリップされます。
3. ヒストグラムをクリックすると、クリック位置の輝度値を等輝度線として画像に重ねます。同じ値はヒストグラム上にも赤い破線と数値で表示されます。「等輝度線を解除」で消去できます。
4. 「輝度範囲を全体に戻す」で元画像の最小値・最大値に戻せます。
5. 「Matplotlib 表示・画像オペレーション」の見出しをクリックすると、操作欄を折りたたみ・展開できます。
6. 操作欄の「＋ 拡大」「－ 縮小」「全体表示」、またはプレビュー上のマウスホイールで表示倍率を変更できます。ホイール操作はカーソル位置を中心に拡大・縮小します。
7. 操作欄でカラーマップ、補間方式、原点、縦横比、カラーバーを変更できます。
8. 保存先を選択し、選択画像または全画像を PNG で保存します。

元画像は変更されません。輝度範囲は表示および保存時のカラーマップ適用に使われます。ズーム倍率はプレビュー表示だけに適用され、保存画像の切り抜き範囲は変更しません。
