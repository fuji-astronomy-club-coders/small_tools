# Gray Colormap Studio

複数の画像を読み込み、グレースケール化・カラーマップ変換・プレビュー・一括保存を行う PyQt6 デスクトップアプリです。FITS の科学画像にも対応しています。

## 主な機能

- 複数画像の読み込み（PNG / JPEG / TIFF / BMP / WebP / FITS）
- TIFF / FITS の画素値を元のデータ型・ビット深度のまま読み込み
- FITS は最初に画像データを持つ HDU を自動選択
- 16-bit 整数や浮動小数点を含む画素値を表示用に正規化してカラーマップ表示
- Matplotlib が提供するカラーマップを選択してプレビュー
- 画素値ヒストグラム（縦軸は対数スケール）
- ヒストグラム上のカーソル位置に対応する画素値・階級・画素数の表示
- 選択画像または読み込み画像すべてへの一括適用
- 出力先フォルダーを指定して一括保存
- 元画像は変更せず、RGB PNG として保存

## 動作要件

- Python 3.10 以上
- PyQt6
- NumPy
- Pillow
- Matplotlib
- OpenCV（headless）
- tifffile
- Astropy

## セットアップ

```powershell
python -m pip install -r requirements.txt
```

## 起動

```powershell
python run.py
```

## 使い方

1. 「画像を追加」から画像ファイルを選択します。FITS は `.fits` / `.fit` / `.fts` に対応します。
2. 左側の一覧からプレビューする画像を選択します。
3. カラーマップを選択するとプレビューが更新されます。
4. 画像の下に表示されるヒストグラムは、画素数を対数軸で表示します。
5. ヒストグラム上にマウスカーソルを移動すると、その位置の画素値・該当階級の範囲・画素数が表示されます。
6. 保存先フォルダーを選び、「すべて保存」または「選択画像を保存」を押します。

保存ファイル名は `元のファイル名_カラーマップ名.png` です。元画像は上書きしません。FITS などの元データの画素値は保持し、カラーマップ表示時のみ画像ごとの最小値・最大値を使って 0～1 に正規化します。
