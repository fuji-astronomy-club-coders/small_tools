# Gray Colormap Studio

複数のグレースケール画像にカラーマップを適用し、プレビュー・一括保存できる PyQt6 デスクトップアプリです。

## 主な機能
- 複数画像の同時読み込み（PNG / JPEG / TIFF / BMP / WebP など Pillow 対応形式）
- Matplotlib が提供するカラーマップを選択してプレビュー
- 選択画像または読み込み画像すべてへの一括適用
- 出力先フォルダーを指定して一括保存
- 元画像は変更せず、RGB画像として保存
- ファイル一覧から画像を選び直してプレビューを切り替え
- グレースケール画像以外も輝度へ変換して処理

## 動作要件
- Python 3.10 以上
- PyQt6
- NumPy
- Pillow
- Matplotlib

## セットアップ
```powershell
python -m pip install -r requirements.txt
```

## 起動
```powershell
python run.py
```

## 使い方
1. 「画像を追加」から複数画像を選択します。
2. 左側の一覧からプレビューしたい画像を選びます。
3. カラーマップを選択します。プレビューは選択と同時に更新されます。
4. 保存先フォルダーを選び、「すべて保存」または「選択画像を保存」を押します。

保存ファイル名は `元のファイル名_カラーマップ名.png` になります。出力は RGB PNG です。
元画像を上書きしません。カラーマップは Matplotlib のインストール環境で利用可能なものを一覧表示します。
